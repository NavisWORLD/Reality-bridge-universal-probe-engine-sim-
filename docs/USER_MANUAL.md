# Reality Bridge User Manual

## Start

Open [`../index.html`](../index.html) for the visual project portal.

## Universe Engine

Open [`../REALITY_BRIDGE_UNIVERSE_ENGINE_ULTIMATE.html`](../REALITY_BRIDGE_UNIVERSE_ENGINE_ULTIMATE.html).

Modes:

- **Orbit** — deterministic procedural planet visualization.
- **Surface** — use WASD/arrows, drag to look, and Space to jump.
- **Device** — inspect the Reality Bridge probe inside the engine; press `X` to toggle exploded internals.

Game actions include world folding, life seeding, outposts, storms, anomalies and time warp.

## Device Digital Twin

Open [`../hardware/REALITY_BRIDGE_PROBE_DIGITAL_TWIN_ENGINE.html`](../hardware/REALITY_BRIDGE_PROBE_DIGITAL_TWIN_ENGINE.html).

Drag to rotate, use the mouse wheel to zoom, switch among shell/X-ray/explode/signals modes, and use the explode slider. It defaults to simulated telemetry. A compatible local probe can be connected over WebSocket.

## Blueprint Lab

Open [`../hardware/blueprints/REALITY_BRIDGE_DEVICE_BLUEPRINT.html`](../hardware/blueprints/REALITY_BRIDGE_DEVICE_BLUEPRINT.html).

Switch between top/front/side/exploded/wiring views, toggle dimensions and labels, open the BOM, and print a fabrication drawing.
