## Practical exercises

- Open the Universe Engine and fold through multiple named worlds.
- Compare surface movement under different simulated gravity values.
- Open Device mode and identify each reference module.
- Open the Blueprint Lab and trace I²C, I²S, UART and USB signal paths.
- Write a pass/fail threshold before running any hardware test.
