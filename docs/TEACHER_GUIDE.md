# Reality Bridge Teacher Guide

## Learning goals

Students should be able to distinguish simulation from measurement, build deterministic procedural systems, inspect multimodal state, understand an open sensor device, and design falsifiable experiments.

### Module 1 — Evidence labels
Classify repository statements as implemented, software-tested, design target, proposed test, or simulation/metaphor.

### Module 2 — Deterministic worlds
Generate multiple named worlds and explain why identical seeds reproduce the same authored world parameters.

### Module 3 — State channels
Change movement/weather/biosphere conditions and inspect the 54-channel display. Discuss why software dimensions are not extra spatial dimensions.

### Module 4 — Device engineering
Use the Digital Twin and Blueprint Lab to identify sensor placement, enclosure geometry, I²C/I²S/UART paths and the firmware packet schema.

### Module 5 — Experimental controls
Design a test using live, replayed, time-shifted, shuffled and disabled sensor conditions.

### Module 6 — Replication report
Publish methods, environment, source revision, failures and null results alongside successful outputs.

## Suggested grading

- 30% reproducibility
- 25% engineering correctness
- 20% experimental controls
- 15% documentation
- 10% interpretation discipline
