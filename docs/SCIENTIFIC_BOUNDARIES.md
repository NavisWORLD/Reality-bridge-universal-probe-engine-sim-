# Scientific boundaries

This repository implements procedural simulation, state evolution, persistence, sensor/public-data adapters, interactive device visualization and an open reference hardware design.

It does **not**, by itself, establish consciousness, new fundamental physics, quantum advantage, precognition, medical diagnosis, or causal astronomical/geophysical influence on local physical reality.

A real earthquake observation may be mapped to a simulated anomaly because that is an authored software rule. NASA APOD is media/context, not a physical measurement of the simulated planet.

The 12D/42D/54D labels are software state dimensions.

The MAX30102 path is treated as an experimental/creative optical waveform channel and is **not a medical device**.
